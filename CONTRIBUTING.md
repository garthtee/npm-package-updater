# Contributing

Thanks for your interest in contributing to NPM Package Updater!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/npm-package-updater.git`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b my-feature`

## Development

- Build: `npm run compile`
- Watch mode: `npm run watch`
- Run tests: `npm test`
- Lint: `npm run lint`
- Format: `npm run tidy`

## Pull Request Process

1. Ensure your code passes linting and tests
2. Update the CHANGELOG.md if applicable
3. Submit a pull request to the `master` branch

## Code Review

All pull requests require approval from a code owner (@garthtee) before merging. This ensures code quality and consistency across the project.

## Questions?

Open an issue if you have questions or need help getting started.
